### **Stage 0: The Hermetic Microkernel, Distributed Orchestrator & Seax Carrier Substrate**

#### **Module 0.1: Zero-Leak Profile Confinement & Stage 0 Trampolines**
* **ClauseOS Base**: `cx.bat`, `cx.ps1`, `cx.sh`, `config/env/00-core.toml`–`40-ml-hub.toml` (`[f01]`, `ADR 0001`, `ADR 0004`) | **Orchestrator Equivalent**: `[c03]` Ch. 12 (`Cobra` CLI entrypoints & environment isolation) | **Agent Harness Equivalent**: `r14` Ep. 12 (Startup Fast-Path & Trust Boundary), `r15` Ch. 2 (Under-300ms Bootstrap Pipeline), `r16` Ch. 2–3 (7-Dimension Config Merge & MDM), `r19` Ch. 5 (6-Layer Config Priority Chain)
* **Shared Concept**: Establishing a zero-leak process sandbox and single-source-of-truth (SSOT) environment compiler before any toolchain binary, compiler, or LLM agent executes—guaranteeing that deleting `.home/` completely resets the machine with zero host OS residue.
* **ClauseOS Substrate Mechanics (`[f01]`, `ADR 0001`, `ADR 0004`)**:
  1. **Symmetrical Root Trampolines (`cx.bat` $\rightarrow$ `cx.ps1`, `cx.sh`):** Single-command invocation from outside or inside the shell (`cx test`, `cx pkg:add`, `cx vm`), preserving `CLAUSE_STATUS="online"` across nested subshells without reboot loops.
  2. **Declarative Modular TOML SSOT (`config/env/*.toml`):** Replaces drifted `.ps1`/`.sh` env scripts with 5 lexical modules (`00-core.toml`, `10-identity.toml`, `20-toolchains.toml`, `30-shell.toml`, `40-ml-hub.toml`), parsed via 8-pass iterative `${VAR}` symbol expansion and platform-normalized paths (`windows` vs. `posix`).
  3. **Known-Folder & XDG Redirection:** Redirects `$HOME`, `$USERPROFILE`, `$APPDATA`, `$LOCALAPPDATA`, `$XDG_CONFIG_HOME`, `$XDG_DATA_HOME`, `$XDG_CACHE_HOME`, `$GIT_CONFIG_GLOBAL`, `$GH_CONFIG_DIR`, and `GIT_SSH_COMMAND` strictly into `${CLAUSE_PROJECT_ROOT}/.home/`.
  4. **Stage 0 Preflight Host Hygiene Redline:** Scrubs CI runner paths (`\scoop\shims`, `/homebrew/`, `/linuxbrew/`) and hard-aborts if unmanaged global `mise`, `scoop`, or `brew` binaries or active host `MISE_SHELL` sessions are detected outside `$CLAUSE_HOME`.
  5. **Cross-Shell PATH Canonicalization (`ADR 0004`):** Enforces `;` vs `:` delimiter discipline in `cx.ps1` and defensive two-pass delimiter splitting in Nushell `env.nu`, plus static parse-time `./mise.nu` generation.
* **Laravel Component Adoption & Target Primitives**:
  * **Target Primitives**: `IBootloader`, `IConfigCompiler`, `IHermeticSandbox`
  * **Created Components**: `config` (Modular TOML SSOT compiler), `console` (Universal `cx` entrypoint & Nushell router), `filesystem` (`.home/` anchor provisioner).
  * **Consumed Components**: `container`, `config`, `console`, `filesystem`, `log` (`$CLAUSE_BOOTSTRAP_LOG`).
* **Quad Model Mechanics**:
  * **Fowler / Clean Arch**: Separated Interface (platform-agnostic TOML manifests vs. OS-specific `cx.ps1`/`cx.sh` bootstrappers), Layer Supertype (invariant `.home/` anchors).
  * **GoF**: Template Method (identical 3-stage boot sequence across Windows/Linux/macOS), Strategy (platform-specific path normalization and tar/curl extraction).
  * **Otwell**: Convention over Configuration (zero manual PATH setup; `config/env/*.toml` auto-discovered in lexical order).
  * **Storer / Systems Discipline**: Zero-Leak Confinement & Fail-Fast Redlines (immediate termination on unmanaged host package managers before a single byte is downloaded).

#### **Module 0.4: Distributed Orchestrator Primitives (`Task → Worker → Manager → Scheduler`) & HashiStack**
* **Tim Boring Base**: *Build an Orchestrator in Go (From Scratch)* (`[c03]`, Chapters 1–13: `Task`, `TaskEvent`, `Worker`, `Manager`, `Scheduler` [`RoundRobin` & `E-PVM`], `Store` [`InMemory` & `BoltDB`], REST API, Health Checks, `Cobra` CLI) | **ClauseOS Base**: `ops/config/{nomad,consul,vault}.hcl`, `cx vm` (WSL2 / Lima), `Pixiecore` + `Packer` MaaS (`ADR 0006`, `ADR 0010`) | **Agent Harness Equivalent**: `r15` Ch. 10 (7-Type 5-Status Task State Machine), `r20` Ch. 10 (`ResourceAwareOrchestrator`), `b21` Ch. 8 & 10 (DAG Scheduling & Operational Lifecycle)
* **Shared Concept**: Stripping away black-box container magic by building the five fundamental primitives of every cluster orchestrator (`Task`, `Worker`, `Manager`, `Scheduler`, `Store`) from scratch in Rust (`Ractor`/`Spawned` OTP actors) and wiring them directly to HashiStack (`Nomad`, `Consul`, `Vault`), `cx vm` micro-instances, and `Pixiecore`/`Packer` bare-metal netbooting.
* **Tim Boring *Cube* Orchestrator Mechanics Mapped to ClauseOS (`[c03]` Ch. 1–13)**:
  1. **Task 5-State Lifecycle & Transition Matrix (`[c03]` Ch. 2–4):** Models every workload (Docker container, Nomad `raw_exec` agent, `cx vm` micro-instance, or DSP render job) as a `Task` (`ID`, `ContainerID`, `Name`, `State`, `Image`, `Cpu`, `Memory`, `Disk`, `ExposedPorts`, `PortBindings`, `RestartPolicy`, `HealthCheck`, `RestartCount`, `StartTime`, `FinishTime`) driven by `TaskEvent` state triggers through a validated finite state machine (`Pending` $\rightarrow$ `Scheduled` $\rightarrow$ `Running` $\rightarrow$ `Completed` | `Failed`, enforced via `stateTransitionMap` and `ValidStateTransition(src, dst)`).
  2. **Worker Execution Engine, FIFO Queue & `/proc` Telemetry (`[c03]` Ch. 4–6):** Each `Worker` owns an inbound FIFO `Queue` (desired state), a `Store` (current state), a runtime driver (`Docker` / `Nomad` / `cx vm`), and a periodic `CollectStats()` loop reading CPU (`idle` vs `nonIdle` delta percentage), `MemTotal`/`MemAvailable`, `DiskTotal`/`DiskFree`, and `LoadAvg`—exposed via REST/RPC endpoints (`GET /tasks`, `POST /tasks`, `DELETE /tasks/{taskID}`, `GET /stats`).
  3. **Manager Control Plane, Reconciliation Loop & Active Health Checks (`[c03]` Ch. 7–9):** The `Manager` maintains cluster-wide `TaskDb`, `EventDb`, `WorkerNodes`, `WorkerTaskMap`, and `TaskWorkerMap` (`[c03]` Ch. 10.6 duplicate-stop bug fix: checking `TaskWorkerMap` before scheduling new work). Runs three concurrent loops: `ProcessTasks()` (dequeue $\rightarrow$ schedule $\rightarrow$ dispatch), `UpdateTasks()` (reconcile worker state as source of truth), and `DoHealthChecks()` (polling task `/health` HTTP endpoints and triggering `restartTask` up to `RestartCount < 3`).
  4. **Pluggable `Scheduler` Interface & Borg's E-PVM Algorithm (`[c03]` Ch. 10):** Separates scheduling into a 3-phase interface (`SelectCandidateNodes` feasibility filter $\rightarrow$ `Score` $\rightarrow$ `Pick`), implementing both `RoundRobin` and Google Borg's **Enhanced Parallel Virtual Machine (E-PVM)** marginal opportunity-cost scheduler (`LIEB = 1.53960071783900203869`, computing `memCost + cpuCost` marginal load deltas across cluster nodes) extended with ClauseOS GPU VRAM / NPU accelerator scoring (`ADR 0003`).
  5. **Pluggable `Store` Interface & Crash-Restart Persistence (`[c03]` Ch. 11):** Decouples `Manager` and `Worker` state behind `Store` (`Put`, `Get`, `List`, `Count`), swapping ephemeral `InMemoryTaskStore` for embedded persistent KV/SQLite WAL storage (`TaskStore`, `EventStore`) so control-plane restarts never orphan running workloads.
  6. **HashiStack, `cx vm` & Bare-Metal MaaS Integration (`ADR 0006`, `ADR 0010`):** Confines `Nomad` (`raw_exec`), `Consul` (service mesh & health checks), and `Vault` (dynamic secret leases) inside `$CLAUSE_HOME/.local/share/`, wraps `wsl.exe` / `limactl` under `cx vm` for ephemeral `k3s` guests, and coordinates `Packer` + `Pixiecore` iPXE netbooting for bare-metal clusters.
* **Laravel Component Adoption & Target Primitives**:
  * **Target Primitives**: `IOrchestratorManager`, `IWorkerNode`, `IScheduler`, `IWorkloadStore`, `IVirtualMachineDriver`
  * **Created Components**: `queue` (`Pending` & worker FIFO task queues), `database` (Persistent `TaskStore` & `EventStore`), `process` (Container/Nomad/VM runtime drivers), `concurrency` (Concurrent manager reconciliation & health-check loops).
  * **Consumed Components**: `http` (Worker/Manager REST & RPC endpoints), `routing` (`/tasks`, `/stats`, `/nodes`), `encryption` (Vault token leases), `console` (`cx vm` & cluster CLI commands).
* **Quad Model Mechanics**:
  * **Fowler / Clean Arch**: Control Plane vs. Data Plane separation (`Manager` administrative state vs. `Worker` execution), Repository (`Store` interface decoupling domain structs from BoltDB/SQLite), Data Transfer Object (`TaskEvent` & `DockerResult`).
  * **GoF**: Strategy (pluggable `Scheduler` implementations: `RoundRobin` vs. `E-PVM`), State (explicit `stateTransitionMap` task finite state machine), Facade (`Manager` API hiding multi-worker placement from CLI users), Command (`TaskEvent` encapsulating start/stop state transitions).
  * **Otwell**: Clean Resource Routing (`/tasks`, `/tasks/{taskID}`, `/stats`, `/nodes`), Expressive CLI Subcommands (`worker`, `manager`, `run`, `stop`, `status`, `node`).
  * **Storer / Systems Discipline**: Authoritative Worker Reconciliation (workers own ground-truth container/process state; manager reconciles periodically without blocking), Bounded Restart Circuit Breakers (`RestartCount < 3`).

#### **Module 0.6: Seax (`.cx`) Language Frontend, Pratt Parser, Macro Expander & Monkey-X Multi-Target Compiler**
* **Thorsten Ball Base**: *Writing An Interpreter In Go* (`[c01]`, Ch. 1–4: Lexer, Pratt Parser, AST, Evaluator, Objects, `HashKey`), *The Lost Chapter: A Macro System For Monkey* (`[c01-lost]`, Ch. 5: `quote`, `unquote`, `ast.Modify`, `DefineMacros`, `ExpandMacros`), *Writing A Compiler In Go* (`[c02]`, Ch. 1–10: Bytecode `code.Make`/`ReadOperands`, Stack VM, Jump Back-Patching `changeOperand`, `SymbolTable` scopes [`Global`, `Local`, `Builtin`, `Free`, `Function`], Call `Frame`s, `OpClosure` & `OpCurrentClosure`) | **Transpiler & Ecosystem Base**: Mark Sibley's *Monkey X (`transcc`)* (`[c05]`), `i2y/jet` (`[c04]` `agent`/`actor`/`needs`/`platform`/`jet_sap`), and revived `andrzejressel/pulumi-gestalt` (`[c06]` `crates/clause-pulumi/`) (`ADR 0011`, `ADR 0012`)
* **Shared Concept**: Building the **Seax (`seaxc`, `.cx`)** compiler in Rust using Thorsten Ball's exact textbook pipeline—extended with syntactic AST macros (`[c01-lost]`), Jet's capability/schema contracts (`[c04]`), and Mark Sibley's Monkey X (`transcc`) multi-target code generation (`[c05]`)—so one Dart-flavored source file compiles directly to **Pure Rust (`Ractor`/`Spawned` OTP actors + `Craft`/`oximedia`/`nih-plug` + revived `pulumi-gestalt`)**, **BEAM (`Core Erlang` / `Glimr` interop)**, and **Client (`TypeScript`/`Wasm` / `Flutter`)**.
* **Thorsten Ball + Monkey X + Jet Mechanics in `compiler/seaxc/` (`[c01]`, `[c01-lost]`, `[c02]`, `[c04]`–`[c06]`)**:
  1. **Single-Pass Lexer & Token Spans (`crates/seax-token`, `crates/seax-lexer` — `[c01]` Ch. 1):** Zero-copy `&str` scanner with `position`/`readPosition`/`peekChar` tracking line/column spans, tokenizing Dart-style C-family syntax (`{ }`, `( )`, `[ ]`, `..` cascades, `->`, `async`/`await`, `schema`, `switch`) alongside first-class transmedia keywords (`audio`, `video`, `midi`, `ndi`, `osc`, `smpte`, `dante`, `dsp`), actor/orchestration keywords (`agent`, `actor`, `pipeline`, `telcom`, `broadcast`, `infra`), and capability keywords (`needs`, `platform`, `provide`, `expose`).
  2. **Pratt Expression & Recursive-Descent Block Parser (`crates/seax-ast`, `crates/seax-parser` — `[c01]` Ch. 2):** Top-Down Operator Precedence parser mapping `prefixParseFn` (`nud`) and `infixParseFn` (`led`) across binding power levels (`LOWEST` $\rightarrow$ `EQUALS` $\rightarrow$ `LESSGREATER` $\rightarrow$ `SUM` $\rightarrow$ `PRODUCT` $\rightarrow$ `PREFIX` $\rightarrow$ `CASCADE` `..` $\rightarrow$ `CALL` $\rightarrow$ `INDEX`), paired with recursive-descent declarations (`AgentDecl`, `ActorDecl`, `PipelineDecl`, `DspDecl`, `InfraDecl`, `SchemaDecl`, `PlatformDecl`) and non-halting error recovery (`expectPeek` / `peekError`).
  3. **Syntactic AST Macro Expansion Pass (`crates/seax-macro` — `[c01-lost]` Ch. 5):** Implements code-as-data `quote` / `unquote` and generic recursive AST rewriting (`ast.Modify(node, ModifierFunc)`), extracting compile-time `macro` definitions (`DefineMacros`) and expanding DSL/platform macros (`ExpandMacros`, e.g., `#if TARGET == "rust"` vs `"beam"`) between parsing and semantic checking.
  4. **Multi-File Contract, Schema & Capability Checker (`crates/seax-checker` — `[c01]` Ch. 3 + `[c04]` Jet AST Guards):** Walks all parsed project ASTs (including "Agent is a Directory" manifests `agent.cx`, `team/`, `skills/`, `mcp/`, `package.seax`) to enforce `expose ... -> Schema` contracts, exhaustive `switch` arms, `oximedia`/`nih-plug` audio/video sample-rate & channel contracts, and compile-time `needs` / `platform` hermetic capability isolation.
  5. **Recursive Symbol Table, Closure Capture & Bytecode/IR Lowering (`crates/seax-symbol`, `crates/seax-ir` — `[c02]` Ch. 3–9):** Resolves bindings across `GlobalScope`, `LocalScope`, `BuiltinScope`, `FreeScope` (capturing free variables for closures), and `FunctionScope` (self-referencing recursive closures via `OpCurrentClosure`), using single-pass jump back-patching (`changeOperand`) and stack-frame base pointers (`Frame`) for Seax's fast embedded bytecode REPL/scripting VM (`seax eval`) alongside the lowered multi-target IR.
  6. **Monkey X (`transcc`) Multi-Target Emitters (`crates/seax-codegen` — `[c05]` + `[c06]` + `ADR 0011` / `ADR 0012`):**
     * **`--target rust` (Primary Native Engine):** Emits borrow-checker-safe Rust (`Arc<T>` / `bytes::Bytes` uniform value representation) lowering `agent`/`actor`/`pipeline` onto **Ractor / Spawned** OTP supervision trees, `dsp` blocks onto zero-allocation **`oximedia` / `nih-plug`** threads and **`vendor/craft/*`** subtrees, and `infra` blocks onto **revived `pulumi-gestalt`** (`crates/clause-pulumi/`) for native YAML-free infrastructure provisioning.
     * **`--target beam` (Distributed Mesh & Glimr Interop):** Emits Core Erlang / `.beam` bytecode (and speaks native Erlang Distribution `erl_dist` / `Joerl`) for multi-node BEAM clusters and Gleam (`Glimr`) services.
     * **`--target client` (Touch Glass & Field Mobile):** Emits TypeScript / WebAssembly and `flutter_rust_bridge` bindings for browser consoles and iOS/Android companion apps.
